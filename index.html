Data Processing di Edge Device

01

Lux Delta Detection

Menghitung lonjakan nilai cahaya secara real-time:

ΔLux = |Lux sekarang − Lux sebelumnya|

Jika ΔLux > 15 Lux → Indikasi ritsleting tas dibuka.

02

Relative Motion RMS Difference

Membandingkan Root Mean Square (RMS) gerakan HP di tas dengan HP pemilik.

ΔRMS = |RMS Tas − RMS Pemilik|

Selisih besar mengindikasikan tas berpindah tanpa pemilik.

Sensor Fusion Rule-Based

Keputusan dibuat dari gabungan data kedua edge device via Cloud MQTT.

CRITICAL_ALERT
